# Business Questions

RAIL-SHIELD is designed to investigate the passenger journey as a connected operational process.

1. Which journeys accumulate the highest arrival delay?
2. Which destination stations show the highest average segment delay?
3. Which disruption types contribute the most delay minutes?
4. Which station-to-station segments repeatedly accumulate disruption?
5. Which connections consume more time than their planned transfer windows?
6. How does reliability vary across passenger/journey categories?
7. Where does friction accumulate within multi-segment journeys?
8. Which operational patterns should be investigated first?

## Interpretation Rule

The project identifies analytical signals and investigation priorities. It does not infer causes that are not represented in the data.
