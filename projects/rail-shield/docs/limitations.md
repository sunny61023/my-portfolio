# Assumptions, Ethics & Limitations

## Data Status

Current records are synthetic/sample data created for portfolio demonstration. They are not official Indian Railways records.

## Metric Status

"Journey Friction Score", connection-pressure signals, and related thresholds are portfolio-designed analytical constructs. They should not be described as official railway KPIs.

## Analytical Limitations

- Small sample data cannot establish real-world operational performance.
- Correlation between a disruption and delay does not by itself establish causation.
- Passenger-level analysis should use anonymized identifiers.
- Production analysis would require documented source provenance, validation and refresh controls.
- Operational recommendations should be tested against domain knowledge and real data before deployment.

## Responsible Portfolio Claim

The project demonstrates data modeling, SQL, EDA, KPI design and dashboard thinking. It does not claim deployment by or affiliation with Indian Railways.
