# Power BI Layer

Planned dashboard pages:

1. **Executive Reliability** — journey volume, on-time rate, average delay and friction score.
2. **Station Reliability** — station-level delay, transfer pressure and recurring disruptions.
3. **Journey Explorer** — drill-through from journey to segment and disruption.
4. **Connection Risk** — vulnerable transfers and missed-connection patterns.

All measures should be documented in the final Power BI delivery.
